## How this repo works

- One code base, one folder per team: `data/teams/<team>/schedule.yaml` (+ `results.json`, `issues.json`); `data/venues.yaml` and `data/drive_times.json` are shared.
- `make build` regenerates every team's `<team>/README.md` + `CALENDAR.md`, this index, `venues.geojson`, and the Pages site data + `.ics` feeds in `docs/`. The site switches teams with `?team=<key>`.
- The daily GitHub Action runs per team: reminders (@-mention → email), closing finished games with the final score, results from the official 3C2A feed, and a `schedule-drift` issue when the feed disagrees.
- Reminder issues are labelled by team (`mbb`, `wbb`). `make test` / `make e2e` run the test suites ([tests/README.md](tests/README.md)).
